# 助手个人消息对话入口

Status: done

## Problem Statement

玩家需要可以从聊天玩家列表找到的固定助手联系人，并通过个人消息接收回复，而不是把指令和结果发到公共聊天。

## Solution

在玩家列表提供虚拟联系人“查鱼助手”，支持打开资料卡和发送文本，回复入口说明并将其保存到请求者的收件箱。本阶段只完成对话入口，不执行鱼种查询。

## User Stories

1. 玩家可以从玩家列表找到联系人并发送消息。
2. 回复只发给请求者，重新打开收件箱仍能读取。
3. 重复请求不重复生成回复，助手不接收玩家物品。

## Implementation Decisions

- 虚拟联系人不创建玩家账号或管理权限；普通玩家之间的寄件保持原行为。
- 客户端基线为 `4.0.25034`。玩家列表 `24/4` 使用普通 u32 数组，资料卡 `24/19` 使用 bytes 包装的 `dgbmlekfpbg`/2002；字段依据见 `docs/debugging-workflow.md`。
- “发送消息”使用 `19/1`，先返回 null 应答，再使用既有 `19/10` 推送；`19/6`、`19/7` 沿用已有邮件读取。
- 回复写入既有邮件表并沿用事务及请求回执。不得改成公共聊天广播，不新增表或迁移，不修改客户端。
- 回滚只需更换原程序，已保存的普通文本邮件无需转换。

## Testing Decisions

- 协议回环覆盖联系人可发现、资料卡类型、先应答后推送、回复持久化、接收者隔离和同请求重放。
- 验证助手不创建玩家账号、不接收物品，保留普通玩家邮件回归。
- 执行完整 `go test ./...`、`go vet ./...`、`go build ./...`；自动测试不替代实机验收。

## Out of Scope

鱼种计算、地图区域定位、GM 管理、物品发放和客户端修改。
